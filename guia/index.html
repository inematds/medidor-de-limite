Em resumo

O medidor-de-limite é um programa pequeno que lê os registros que o Claude Code e o Codex já gravam no seu computador e mostra para onde foi o limite da sua assinatura. Serve para quem usa muito esses assistentes, principalmente com robôs e tarefas agendadas, e bate o limite da semana sem saber quem gastou. Ele aponta os projetos que mais gastam e as tarefas repetidas que dava para juntar. Precisa só de Python 3: não usa internet nem chave, e não apaga nem pausa nada.

O que é

Um ponteiro para a sua assinatura

O plano diz que você tem um limite por semana, mas não diz quanto é em tokens nem quem está gastando. O medidor tira isso dos seus próprios registros.

⏱️ Ponteiro da semana

Verde abaixo de 70% do teto, amarelo até 90%, vermelho acima. Sempre com o rótulo escrito, não só a cor.

📊 Quem gasta

Top 10 por pasta de projeto, por sessão e por rotina (as tarefas de robô agrupadas pelo primeiro pedido).

🔁 Quem repete

Robôs com o mesmo pedido rodando no mesmo dia, a menos de 1 hora um do outro: candidatos a virar uma execução só.

Como funciona

Lê, soma, compara com o seu teto

Tudo acontece no seu computador. O conteúdo das conversas nunca aparece: só números e o começo do pedido, com até 80 caracteres e sem e-mail, link ou caminho de pasta.

Registros do Claude Code e do Codex→ Soma por dia, projeto, sessão e rotina→ Peso por tipo de token→ Teto da semana que estourou→ Ponteiro + top 10 + repetidos

Tokens processados e peso

Quase tudo o que passa pelo modelo é cache lido, que custa pouco. Por isso o ponteiro usa o peso: cada tipo de token conta na proporção do preço público (Claude: novo 1, cache escrito 1,25, cache lido 0,1, saída 5). O relatório mostra os dois números.

O teto é calibrado por você

O plano não publica o limite em tokens. Quando o limite corta, o Claude Code grava "You've hit your weekly limit" no registro. O comando calibrar acha essa mensagem e soma o que você gastou naquela semana: esse é o seu teto. Uso no site, no app ou em outra máquina não está aqui.

Pré-requisitos

Python 3 e o histórico das suas sessões

Funciona onde o Claude Code ou o Codex já rodam e gravam os registros (~/.claude/projects e ~/.codex/sessions). Escolha o seu sistema e cole os comandos, um de cada vez.

Linux (Ubuntu, Debian)

O Python 3 já vem instalado. Se faltar o git:

sudo apt install -y git python3
python3 --version

Mac

O primeiro comando instala as ferramentas da Apple, que trazem git e Python 3.

xcode-select --install
python3 --version

Windows (WSL)

No PowerShell como administrador, instale o Ubuntu e reinicie. Depois, no Ubuntu:

wsl --install
sudo apt install -y git python3

Se o Claude Code roda no Windows (fora do WSL), aponte para a pasta dele no passo 2 com --claude-dir /mnt/c/Users/SEU_USUARIO/.claude/projects; o Codex do Windows entra com --codex-home /mnt/c/Users/SEU_USUARIO/.codex. O que roda do lado Windows e você não apontar fica fora da conta.

Guia de uso · passo a passo

Do zero ao ponteiro em 5 minutos

Os comandos são os mesmos no Linux, no Mac e no Ubuntu do WSL.

1

Baixe o medidor

É uma pasta com um arquivo Python e a página do ponteiro. Não instala nada no sistema.

git clone https://github.com/inematds/medidor-de-limite.git
cd medidor-de-limite
2

Primeira leitura: os últimos 7 dias

Mostra os totais do Claude Code e do Codex, o top 10 de projetos, o top 10 de rotinas e os repetidos. Histórico de 8 GB leva menos de meio minuto, porque ele lê linha a linha e pula o que não é contagem.

python3 medir.py relatorio

Para outra janela, use --dias 14. Se você tem duas contas do Codex, cada uma em uma pasta, ele acha ~/.codex, ~/.codex-2 e a $CODEX_HOME; outra pasta entra com --codex-home.

3

Ache o seu teto na semana que estourou

Procura nos últimos 35 dias a mensagem de limite semanal e soma o que foi gasto naquela semana. Confira o número e grave.

python3 medir.py calibrar
python3 medir.py calibrar --salvar

Não achou nenhum corte? Diga quando foi, ou ponha um número à mão. O número é na unidade peso, a mesma que o relatorio mostra por ferramenta: parta do peso de uma semana em que você chegou perto do limite.

python3 medir.py calibrar --estourou-em "2026-10-26 18:00" --salvar
python3 medir.py calibrar --ferramenta codex --teto 60000000 --salvar
4

Abra o ponteiro

Gera uma página com o ponteiro animado, as barras por projeto e por rotina, o gráfico dia a dia e a tabela de repetidos. Funciona no celular.

python3 medir.py html --saida medidor.html
xdg-open medidor.html

No Mac, troque xdg-open por open. No WSL, use explorer.exe medidor.html.

5

Junte ou pause os repetidos, você mesmo

O medidor só sugere. Ache o timer ou a tarefa agendada que dispara a rotina repetida e decida se junta numa execução só.

systemctl --user list-timers
crontab -l
6

Compartilhar sem expor seus projetos

Com --anonimo, as pastas que não estão numa lista de nomes públicos viram privado-1, privado-2… e os pedidos delas somem. A lista é um arquivo de texto com um nome por linha.

python3 medir.py html --anonimo --publicos publicos.txt --saida medidor.html

Limites honestos

O que o medidor não sabe

Melhor saber antes de confiar no ponteiro.

Teto
É uma estimativa sua, não um número oficialVem da semana em que o limite cortou. Se o seu jeito de usar muda muito, calibre de novo.
Outros lugares
Site, app e outras máquinas não aparecemEles gastam do mesmo limite, mas os registros ficam em outro lugar.
Codex
O corte quase nunca fica gravadoO teto do Codex costuma ser à mão (--teto).
Repetidos
Pedido parecido não é sempre trabalho duplicadoUm lote de 40 resumos com o mesmo molde aparece como grupo. Por isso a economia mostrada é "pelo menos" o custo fixo de cada execução extra, e "até" o total se for o mesmo trabalho.
Python 3 (só biblioteca padrão)
